INF 321 - PROJETO E DESENVOLVIMENTO DE SISTEMAS PARA A WEB

Professor: Lucas Vegi

Descrição:

O objetivo da disciplina é introduzir ao aluno conceitos arquiteturais básicos da Web, focando em aspectos de projeto e implementação de sistemas e softwares para a mesma; Treinar o desenvolvimento de aplicações cliente-servidor e de sistemas com comunicação por troca de mensagens; Treinar o desenvolvimento de aplicações multiplataforma; Introduzir o aluno à linguagens de marcação e de folhas de estilo; Prover contato inicial do estudante com tecnologias de desenvolvimento backend; Introduzir, por meio de aplicações Web, conceitos de comunicação assíncrona cliente-servidor e acesso a bancos de dados no servidor.

Lista de tópicos:

  1. Introdução à Web.
  2. Linguagens para Desenvolvimento frontend.
  3. Linguagens e Frameworks para Desenvolvimento backend.
  4. Introdução à Middleware.
  5. Tópicos Avançados em Web.
